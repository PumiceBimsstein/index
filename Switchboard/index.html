Features

便利な機能群

複数のプロジェクトを並行して進めるときでも、作業場ごとに頭を切り替えられます。

作業場（プロジェクト）切替

「共通メモ」と、「プロジェクト」をサイドバーから切替える。作成・名前変更・並べ替えも可能。

自由配置ボード＆カード連結

拡大縮小できるボードにカードをドラッグ配置。カード同士の関連付け、折りたたみ・複製・別プロジェクトへの移動もできます。

カードの「状態」設定

「未着手」「調査中」「完了」など、プロジェクトごとに状態の名称・色・並び順をカスタマイズ。状態はホイール操作で素早く変更できます。

作業スケジュール通知

固定時刻やランダム時間帯、毎日・曜日指定・単発日付で予定を登録。時刻が来るとお知らせし、15分スヌーズやスキップにも対応します。

背景＆スタイルの着せ替え

作業場ごとの背景色と模様に加えて、アプリ全体の雰囲気を変えられるスタイル切替が可能。

Markdown 書き出し

すべてのカード、あるいは選んだカードを Markdown 形式のファイルとしてダウンロードできます。

Local First

あなたのデータは、あなたのブラウザに。

Switchboard は外部サーバーにノート内容を送信しません。すべての作業データは端末のブラウザ内に自動保存されます。

  • ✓ログイン・会員登録なしで開いた瞬間から利用可能
  • ✓操作ミスしても UNDO（Ctrl+Z / Cmd+Z）でやり直し可能
  • ✓設定メニューからいつでも JSON バックアップを書き出し・復元
IndexedDB 自動保存 編集内容は即座にブラウザ内のストレージへ記録されます。
JSON バックアップ PC の引っ越しや定期保存用に、全データを1ファイルで保存・復元できます。
Markdown エクスポート 書いたメモは標準的な Markdown としていつでも外へ持ち出せます。
FAQ

よくある質問

利用にあたってアカウント登録や料金は必要ですか？

いいえ、不要です。ページを開けばそのまま無料でお使いいただけます。

スマートフォンでも使えますか？

はい。画面幅が狭い環境では、片手で扱いやすい縦リスト表示に切り替わり、ドラッグで並び替えやカード連結も行えます。

別のパソコンやブラウザにデータを移せますか？

サイドバーの「設定 ＞ バックアップ書き出し」から JSON ファイルをダウンロードし、移行先の Switchboard で「バックアップ復元」を行うことでそのまま引き継げます。

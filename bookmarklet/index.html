はじめに

ebook-library は、dbook と BOOK☆WALKER で購入済みの書籍を集め、一覧にして CSV や JSON で出力するツールです。データはこのブラウザ内に保存され、サーバーには送信されません。

1. ブックマークレットを登録する

「bookmarklets」ボタンを開き、dbook・BOOK☆WALKER それぞれのボタンをブックマークバーへドラッグします。

ブックマークバーが表示されていない場合は Ctrl + Shift + B（Mac は Cmd + Shift + B）で表示できます。

2. 書籍を取得する

dbook は購入履歴のページ、BOOK☆WALKER は保有書籍一覧のページを開き、「一覧を取得」を押すと、購入済みの書籍だけが取り込まれます。BOOK☆WALKER では保有書籍一覧ページで同じように実行します。ページをまたいで取得する場合は、BOOK☆WALKER の確認ダイアログで次のページへ進めます。取得データは各サイトごとにブラウザへ蓄積されます。

3. ライブラリへ取り込む

取得したサイトで「データをコピー」を押してから、ebook-library の library タブで「クリップボードから追加」を押します。

同じ書籍は重複して追加されません。読み取りが許可されない場合は json タブの入力欄に貼り付けて「マージして反映」を押してください。

4. 一覧を整理する

検索欄とサイトの絞り込みで表示を絞れます。列見出しを押すと並べ替えられ、その順序は保存されるので、出力やコピーも同じ順になります。チェックボックスで書籍を選ぶと、出力とコピーは選択した書籍だけが対象になります。何も選ばないときは表示中のすべてが対象です。

5. 出力する

「JSONをコピー」はクリップボードへ、「JSONを出力」「CSVを出力」はファイルとして保存します。

6. json タブで直接編集する

json タブでは一覧の内容を JSON として確認・編集できます。「置き換えて反映」は一覧全体を入力内容で置き換え、「マージして反映」は同じ書籍を更新しつつ新しい書籍を追加します。JSON に誤りがある場合は、エラーの位置が表示されます。

注意

書籍データはブラウザに保存されます。ブラウザのデータを消去すると一覧も消えるため、必要に応じて JSON か CSV を出力して保管してください。

ブックマークレットは、サイトの構造が変わると動かなくなることがあります。
